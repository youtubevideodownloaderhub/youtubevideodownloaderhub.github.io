YouTube Video Info Lookup: Title, Author, Duration, and More

How to look up any public YouTube video's title, channel, description, and thumbnail without opening YouTube.

Sometimes you only need the facts about a video: its exact title, who uploaded it, and a thumbnail you can show in a document. YouTube provides this through a public service called oEmbed, which returns the title, author, and thumbnail for any public video. This guide explains what oEmbed provides, how to use it, and what it cannot tell you, so you know exactly what a video-info lookup can and cannot do before you rely on it.

What oEmbed returns

Send a request to youtube.com/oembed with the video URL, and YouTube replies with a small JSON object containing the title, the author name, the author channel URL, the video type, and thumbnail URLs in several sizes. It does not include the view count, the like count, the duration, or the description, because oEmbed is designed for embedding, not analytics. For most everyday needs, such as confirming which video a link points to or getting its proper title for a citation, that is exactly enough.

How to use it yourself

In a browser, open https://www.youtube.com/oembed?url= followed by the video URL and &format=json. You will see the raw JSON in the page. Our video-info tool on this site does the same thing with a friendly display: paste the link, and it shows the title, author, thumbnail, and a link to watch the video. Because the request goes from your browser to YouTube, no account or API key is needed, and nothing you enter is stored.

What it cannot do

oEmbed cannot see private videos, deleted videos, or videos that YouTube has removed. It cannot tell you how long a video is, how many views it has, or whether comments are enabled. For those details you need the YouTube Data API, which requires a Google Cloud API key and has a daily quota. If a video-info lookup fails while the video plays fine on YouTube, the usual cause is a malformed URL, an age restriction, or a temporary YouTube outage.

Practical uses

Teachers use video-info lookups to verify links in lesson plans before sharing them with students. Writers use them to get exact titles for citations. Developers use oEmbed to generate link previews in apps and forums. If you manage a website that links to many videos, checking each link with oEmbed is a quick way to catch broken or removed videos before your readers do, and it is far faster than opening every video by hand.

Verify links before you share them

A link that looks right can still point to the wrong video, a deleted video, or a video that has been made private since you copied it. Checking takes ten seconds with a video-info lookup and saves embarrassment later, especially if the link is going into a lesson plan, a work document, or a published article. Paste the link into the tool, confirm the title and the author match what you expected, and open the thumbnail to be sure. If the title is in a language you do not recognise, or the author is not the channel you expected, you may have copied the wrong link or a link with a typo. For a document with many links, check them all in one pass and note any that fail, so you can replace them before anyone else clicks. Broken links make a document look careless, and a quick verification pass is the cheapest quality check there is.

Frequently Asked Questions

What information can I look up?

For public videos: title, author name, author channel URL, thumbnail image, and the video page link. Duration and view counts are not included in the basic public data.

Does this work for private videos?

No. Private, unlisted-with-restrictions, and deleted videos return no public information.

Is looking up video info legal?

Yes. This uses YouTube's public oEmbed data, which YouTube itself provides for embedding.
